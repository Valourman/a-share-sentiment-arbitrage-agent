面试官必问：本阶段的核心考点与标准话术

Q1: 为什么在 Agent 项目中必须使用 Pydantic 做强类型校验？
回答核心：大模型输出是不稳定的自然语言或 JSON 文本。如果缺少确定性验证，下游模块就会随时因缺少字段或类型错误而崩溃。我们在架构中使用 Pydantic V2 约束所有 Schema，当模型输出格式或字段范围（如得分不在 -1.0 到 1.0）不合规时，系统能捕获 ValidationError 并直接将其作为反馈消息回传给大模型，驱动其自主修正（Self-Correction），保障整个 Agent 链路不崩盘。
Q2: 为什么市面通用的情感分析模型（如 BERT 或通用大模型）在 A 股舆情上经常“翻车”？
回答核心：股民语言具有高度隐蔽的反讽性和密集的行话隐喻。例如“好耶，主力又送钱了，接着跌”，字面上包含“好”、“送钱”等强积极词，通用模型极易判断为看多。我们在预处理与提示词架构中植入了“黑话字典匹配”和“反讽模式检测”，通过先消歧后打分的思维链（COT）机制，彻底解决了正话反说导致的误判。
